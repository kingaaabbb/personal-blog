### Add a Project

Showcase your personal projects here. Edit the `projectConfig` array in `src/config.ts` to add new projects.

### Project Format

```typescript
{
    name: 'Project Name',
    cover: '/assets/project-cover.jpg',
    url: 'https://github.com/yourname/project',
    description: 'Project description',
    tags: ['Astro', 'TypeScript']  // optional
}
```
